Bug report samples

BUG-042 Checkout total shows $0.00 when applying coupon code on empty cart Critical
Environment
demo.opencart.com · Chrome 124 · Windows 11
Steps to reproduce
  1. Open the site and ensure the cart is empty
  2. Navigate to the checkout page directly via URL
  3. Enter coupon code SAVE10 in the coupon field
  4. Click "Apply coupon"
  5. Observe the order total displayed
Expected vs actual
Expected
An error message is shown: "Your cart is empty. Add items before applying a coupon."
Actual
Coupon is accepted and order total displays as $0.00, allowing a potentially free order submission.
Severity / Priority
Critical / P1 — Business logic failure, potential revenue loss
BUG-078 Search results not filtered when price range slider is used on mobile High
Environment
demo.opencart.com · Safari 17 · iPhone 14 (iOS 17.4)
Steps to reproduce
  1. Open the site on a mobile device or Chrome DevTools mobile view
  2. Navigate to any product category page
  3. Use the price range slider to set a max price of $50
  4. Tap outside the slider to apply the filter
  5. Observe the product list
Expected vs actual
Expected
Product list filters to show only items priced $50 or below.
Actual
All products remain visible regardless of the selected price range. Filter has no effect on mobile.
Severity / Priority
High / P2 — Broken filter on mobile, affects UX significantly
