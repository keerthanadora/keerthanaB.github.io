Bug report samples

BUG-001 Checkout total shows ₹0 when coupon applied to empty cart Critical
Environment
E-Commerce App · Chrome 124 · Windows 11 · Test environment
Steps to reproduce
  1. Log in to the application and ensure the cart is empty
  2. Navigate directly to the checkout page via URL
  3. Enter a valid coupon code in the discount field and click "Apply"
  4. Observe the order total displayed on screen
Expected vs actual
Expected
Validation error shown: "Cart is empty. Add products before applying a coupon."
Actual
Coupon applies successfully and order total displays as ₹0, allowing a potentially free order to be placed.
Severity / Priority
Critical / P1 — Business logic failure with potential revenue impact
BUG-002 Search returns no results for valid product name with trailing space High
Environment
E-Commerce App · Firefox 125 · Windows 11 · Test environment
Steps to reproduce
  1. Navigate to the product search page
  2. Type a valid product name followed by a single trailing space (e.g. "Laptop ")
  3. Click the Search button or press Enter
  4. Observe the search results
Expected vs actual
Expected
Search input is trimmed and results for "Laptop" are displayed correctly.
Actual
"No results found" message is shown. Application does not trim whitespace before querying.
Severity / Priority
High / P2 — Poor UX, users unable to find products due to input handling issue
BUG-003 API returns 200 OK for POST /cart/add with negative item quantity Medium
Environment
REST API · Postman v10 · Test environment
Steps to reproduce
  1. Open Postman and send a POST request to /cart/add
  2. Set request body: {"productId": 12, "quantity": -3}
  3. Observe the HTTP response status and body
Expected vs actual
Expected
400 Bad Request with error message: "Quantity must be a positive integer."
Actual
200 OK returned. Item added to cart with quantity -3, corrupting the cart total calculation.
Severity / Priority
Medium / P2 — API input validation missing, data integrity risk
